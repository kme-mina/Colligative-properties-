# Colligative Properties of Solutions — Interactive Simulation

**KME Mina — Kinetic Molecular Engineering – Mina**

A free, single-file, fully offline interactive simulation that shows how the concentration of a dissolved
substance changes four colligative properties together:

- vapor-pressure lowering (Raoult's law)
- boiling-point elevation
- freezing-point depression
- osmotic pressure (van 't Hoff, dilute-solution form)

Choose the solute (glucose, sucrose, urea, NaCl, CaCl₂, AlCl₃), move the molality and temperature sliders,
and watch the particle animations, numbers and graphs update. Includes a red-blood-cell application.

## Run it
Open `index.html` in any modern browser (desktop or phone). No installation, no server, no internet connection.
On GitHub Pages: enable Pages for this folder and open the published URL.

## Notes on accuracy
- Ideal-dilute-solution model: results become less accurate at high concentration (stated in the simulation).
- The particle animations are illustrative; the "Simulated" pressure shown in the vapor-pressure panel is computed
  from the animation's particle counts, not an experimental measurement.
- Numbers shown in the summary cards are computed deterministically from the equations in the page source.

## Privacy
The page makes no network requests and collects no data. All code is plain, readable HTML/CSS/JavaScript in `index.html`.
